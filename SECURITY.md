# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability or confidentiality issue in the BCA Upper Cafe project, please report it privately to the project security contact:

- Email: kabsek30@bergen.org

Please do NOT create a public issue or post the vulnerability to a public forum.

When you report, include:

- A clear description of the vulnerability and the affected components.
- Steps to reproduce the issue, including any proof-of-concept code or commands. If including PoC, ensure it does not include real student data.
- Any impact assessment you can provide (data exposed, affected users, etc.).
- Your preferred contact method and whether you consent to be credited in a fix or advisory.

## Response process and timeline

- We will acknowledge receipt within 72 hours.
- We aim to triage and respond with an initial plan within 7 calendar days.
- Critical vulnerabilities will be prioritized for immediate mitigation.
- We will coordinate disclosure and remediation and will provide a public advisory or patch once the issue is resolved.

## Disclosure policy

- Please do not disclose the vulnerability publicly until the maintainers have had a chance to remediate or coordinate disclosure.
- We follow a coordinated disclosure process and will work with reporters to determine an appropriate timeline.

## Safe harbor

- Reporters acting in good faith to improve project security will not be penalized for their research or for responsibly reporting vulnerabilities.

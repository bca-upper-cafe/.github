# Code of Conduct

## Our Standards

The BCA Upper Cafe project is intended to be a welcoming, respectful, and constructive project for the Bergen County Academies community.

We expect all contributors and participants to:

- Be respectful and considerate of others.
- Give constructive feedback and accept reasonable criticism.
- Keep discussions focused on the project's technical and community goals.
- Respect different levels of experience, backgrounds, and perspectives.
- Protect student, teacher, and school information.
- Report security or privacy concerns responsibly rather than publicly disclosing them.

Unacceptable behavior includes:

- Harassment, discrimination, bullying, threats, or personal attacks.
- Trolling, deliberate disruption, or bad-faith participation.
- Publishing private or identifying information without permission.
- Sharing confidential school, student, teacher, or administrative information.
- Exploiting or attempting to exploit the application's systems, accounts, or data.
- Any other conduct that would reasonably make the project unsafe or unwelcoming.

## Project-Specific Expectations

Because this project may interact with school-related information, contributors must take additional care with privacy and security.

**Do not submit real student or teacher data, credentials, API keys, authentication tokens, attendance records, schedules, or other private information in issues, pull requests, commits, screenshots, or examples.**

Use fictional or anonymized data when demonstrating functionality.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, commits, or other contributions that violate this Code of Conduct. Depending on the severity or frequency of the behavior, maintainers may also restrict or remove participation in the project.

Reports will be reviewed as promptly and fairly as reasonably possible.

If you experience or witness unacceptable behavior, contact a project maintainer privately rather than escalating the situation publicly.

## Scope

This Code of Conduct applies to project spaces, including GitHub repositories, issues, pull requests, discussions, and other official project channels.

It also applies when an individual is representing the BCA Upper Cafe project in public or community spaces.

## Attribution

This Code of Conduct is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/version/3/0/), with additional guidelines for the privacy and security requirements of the BCA Upper Cafe project.
